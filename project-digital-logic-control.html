Virtual EV Transmission — Discrete Logic Gearbox

A four-speed gearbox controller built entirely from logic chips—no microcontroller or firmware.

Overview

I built this project to understand how a circuit can store and change state without software. One button advances through four virtual gears, and two LEDs show the current gear as a two-bit binary number.

  • My role: solo logic design, breadboard build, and testing.
  • Main parts: flip-flops to remember the gear, XOR gates to choose the next gear, and a Schmitt trigger to clean the button signal.
  • Status: shift-up works reliably; shift-down is the next revision.

How it works

01Press buttonThe driver requests the next gear.
→
02Clean signalThe circuit turns switch bounce into one pulse.
→
03Choose next stateLogic gates calculate the next gear.
→
04Store gearTwo flip-flops remember the result.
→
05Show resultLEDs display 00, 01, 10, or 11.

State, in plain English: information the circuit remembers. Here, two stored bits are enough to represent four gears.

Design

The gear sequence is 00 → 01 → 10 → 11 → 00. The XOR gates decide which stored bit must change, and the flip-flops update both bits together when they receive a clean button pulse.

Main challenge

A mechanical button does not switch cleanly. Its contacts bounce for a few milliseconds, so one press originally looked like several presses and skipped gears. A 74HC14 Schmitt trigger filters that noisy edge into one dependable pulse.

Shorter, better-organized breadboard wires also reduced unwanted transitions. This project made it clear that correct logic equations are only part of a reliable physical circuit.

Result

The shift-up cycle now works repeatedly on the breadboard. The next step is adding a second input and logic for shifting down.
