Digital Logic Control Unit (Virtual EV Transmission) — In Progress

Hardware-based state machine design for validating digital powertrain logic.

Objective

Design and validate a hard‑wired digital state machine that behaves like a 4‑speed manual transmission for an EV testbed. The project proves out the core “virtual gearbox” logic using discrete TTL, so critical state decisions don’t depend on microcontroller firmware.

System architecture

Discrete logic architecture:

  • Reference input: Mechanical shift lever with SPDT momentary switches representing driver intent.
  • Controller: 74LS‑series TTL logic implementing the state machine in hardware.
  • State machine: 74LS192 synchronous up/down counter tracking the “virtual gear” (N, 1, 2, 3, 4).
  • Visual feedback: 74LS47 BCD‑to‑7‑segment decoder driving a common‑anode LED display.
  • Safety logic: 74LS08 (AND) and 74LS00 (NAND) gates enforcing hard limits to prevent over‑shifting.

Technical implementation

Wave 1: Signal conditioning & safety

A “Wave 1” conditioning layer cleans up mechanical inputs and prevents illegal states before they ever reach the counter:

  • 74LS14 Schmitt trigger inverter: debounces noisy switch contacts and converts bouncy edges into clean clock pulses.
  • 74LS08 AND gates: implement a hard‑stop interlock so “shift up” only clocks when the current gear is less than 4.
  • 74LS00 NAND gates: provide inverted logic and simple latching to stabilize transitions during rapid shifts.
  • 74LS32 OR gates: merge multiple inhibit conditions (limits, emergency stop) into a single block signal.

Hardware integration

The logic unit is built on a breadboard as a self‑contained module. A 4‑bit parallel bus exposes the current gear to a separate microcontroller, which can then drive motors or displays while the discrete logic owns the state machine.

Power regulation

A dedicated LM2596 buck converter provides a stable, isolated 5.0 V logic rail so the TTL gates stay within spec even when the main drive motor causes current spikes on the rest of the system.

Engineering impact & skills

  • Digital logic design: Built a synchronous state machine using discrete counters, decoders, and glue logic.
  • Signal integrity: Solved switch bounce and illegal state transitions with Schmitt triggers and hard interlocks.
  • System integration: Defined a clean 4‑bit interface so a microcontroller can consume gear state without owning the logic.
