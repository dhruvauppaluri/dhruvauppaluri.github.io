FPGA Studio — Native macOS HDL IDE

A native Mac app for writing, simulating, and programming FPGA projects without setting up a separate toolchain.

Download v2026.09.1 View source

Overview

FPGA development usually requires several separate programs. FPGA Studio brings the common steps into one Mac app, so a user can move from code to a working circuit board without configuring every tool by hand.

  • My role: independent designer and developer.
  • Current release: a downloadable preview for Apple-silicon Macs.
  • Proven result: the app builds and programs a blinking-light design on a Terasic C5G board.
  • Built with: SwiftUI and open-source tools for checking, simulation, building, and programming.

FPGA, in plain English: a chip whose internal digital circuit can be rearranged for a specific job. The code describes hardware rather than a normal sequence of software instructions.

What I built

I built the editor, project browser, waveform viewer, guided workflow, diagnostics, and board-programming safeguards. Beginner mode recommends the next step and explains unfamiliar terms; experienced users can open the raw logs and build details.

The app packages tools such as Yosys, GHDL, and openFPGALoader behind one interface. Those tools do the underlying FPGA work; my contribution is the native application and the reliable workflow that connects them.

Main challenge

The hardest part was making several command-line tools feel like one dependable app. I isolated each build, streamed useful progress, supported cancellation, and checked that the selected board and output file matched before allowing a hardware write.

I also kept the project folders open and portable. Source files remain ordinary files, so using FPGA Studio does not lock a project into the app.

Current status

The released preview completes the full demonstrated workflow on a Terasic C5G board. It is not yet a replacement for every feature in Intel Quartus: advanced memory, signal-processing, and permanent-flash paths still need more hardware testing.

Next I am improving the guided labs, finishing permanent-flash validation, and preparing a smoother signed release.
