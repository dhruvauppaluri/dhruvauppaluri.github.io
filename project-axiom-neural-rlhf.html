Axiom — Neural RLHF

Your brain as the reward model: three AI agents compete to explain a topic while a Muse S headband measures engagement, focus, and valence — no clicks, no thumbs-up, just neural response.

github.com/anishesg/axiom

Project Overview

  • Role: collaborator (WeaveHacks 4, June 6–7, 2026)
  • Event: WeaveHacks 4 (June 6–7, 2026)
  • Hardware: Muse S EEG headband (256 Hz over BLE on macOS)
  • Stack: Python backend (BrainFlow, signal processing, neural reward model), React/TypeScript frontend, Redis streams, Weave tracing, OpenAI agent arena
  • Repository: github.com/anishesg/axiom

Objective

The idea was to skip explicit human feedback entirely. Instead of rating which AI explanation you prefer, you read three competing responses while wearing an EEG headband — and your brain’s response becomes the reward signal. Agents that resonate with you get reinforced over rounds; the ones that lose adapt from your neural feedback. No clicking, no typing a score. Just read, think, and let engagement, focus, and valence do the judging.

We built this in a weekend at WeaveHacks 4. The repo is called Axiom — a separate hackathon project from my solo robot stack, Apollo 1.

System architecture

  • Acquisition: Muse S streams EEG at 256 Hz through BrainFlow (native BLE, band-power and asymmetry features).
  • Brain state engine: derives engagement (β/(α+θ)), focus (β/α), valence (frontal alpha asymmetry), cognitive load (θ/α), and relaxation from live band powers.
  • Neural reward model: maps brain state to per-agent reward scores after each 12-second reading window.
  • Agent arena: three personas via OpenAI — Researcher (depth), Storyteller (narrative), Engineer (practical) — compete on the same topic each round.
  • Adaptation loop: losing agents receive feedback derived from neural rewards; over 3–5 rounds the ensemble drifts toward your preferred style.
  • Infrastructure: Redis for EEG streams and pub/sub reward broadcast; Weave (@weave.op()) traces the full neural → agent → reward pipeline.
  • Frontend: dashboard at localhost:5173 — calibration, topic pick, live reading UI, round results.

Demo flow

  1. Calibrate — 20 s baseline recording (skippable in demo mode).
  2. Choose a topic — custom prompt or preset.
  3. Read — each agent’s response displays for 12 s while EEG is recorded.
  4. Results — neural rewards computed, round winner announced.
  5. Adapt — underperforming agents get neural-derived feedback for the next round.
  6. Repeat — agents converge on your preferences over several rounds.

Simulation mode (./run_demo.sh --sim) runs the full stack without a headband, which was essential for development when Bluetooth pairing or signal quality was fighting us.

Key signals

Signal Source Meaning
Engagement β / (α + θ) Locked in, interested
Focus β / α Deep processing
Valence FAA (AF8 − AF7 α) Positive vs negative affect
Cognitive load θ / α Confused, overwhelmed
Relaxation α dominance Disengaged

Reflection

This was my first time working with live EEG in a product-shaped loop, not just plotting raw traces. The hard part was not the agents — it was trusting the signal: motion artifacts, bad electrode contact, and whether a spike in beta actually meant “this explanation is good” or “I am confused.” Building a sim mode early saved us; so did treating reward as a smoothed brain-state vector instead of a single noisy sample.

The architecture — stream EEG, classify state, score agents, trace everything — is the piece I took away. It sits in a different lane from the embedded and hardware projects on this site, but the signal-processing instinct is the same: filter before you act on the data.

Repository

Source and setup instructions live in the team repo: github.com/anishesg/axiom. Run ./setup.sh once, then ./run_demo.sh (or --sim) and open the frontend on port 5173.
