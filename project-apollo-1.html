Apollo 1 — EEG Brain-Wave Controlled Rover

A four-wheel rover whose speed changes with focus measured by an EEG headband.

View the repository

Overview

Our team built Apollo 1 in 24 hours at WeaveHacks. Instead of using a joystick, the rover responds to sustained focus from a Muse S EEG headband.

  • My role: built the rover, motor electronics, firmware, and computer-to-rover connection.
  • Team work: teammates built the EEG processing and AI-agent system.
  • Hardware: Arduino Uno, four motors, distance sensor, camera, and Muse S headband.
  • Purpose: explore hands-free control that could support people who cannot easily use conventional input devices.

How it works

01Measure focusThe headband reads patterns in brain activity.
→
02CompareSoftware checks the reading against a personal baseline.
→
03Create commandMore sustained focus becomes more drive power.
→
04Send to roverPython passes the command to the Arduino.
→
05Move safelyMotors respond while sensors watch for obstacles.

EEG, in plain English: a non-invasive way to measure electrical activity at the scalp. It does not read thoughts; this demo uses broad changes associated with focus.

What I built

I assembled the chassis, wired four independent motor stages, mounted the camera and distance sensor, and refined the Arduino and Python software that carried commands to the wheels. I also made the outputs stay off during startup so the rover would not jump when it reset.

The separate Axiom project explains the team’s EEG and AI work. My responsibility was the last mile: making a valid focus update become predictable physical motion.

Main challenge

The rover sometimes barely moved even though the software commands looked correct. Measuring the power line showed that disposable 9 V batteries dropped too much voltage when several motors started together. The problem looked like software, but it was electrical.

I also used simple one-motor tests to separate wiring faults from communication faults. That made debugging faster because I could prove each layer worked before reconnecting the full system.

Result and next step

We completed a working hackathon demo in which focus data controlled the rover. The next hardware version needs a battery designed for higher current so all motors and sensors can run reliably at the same time.

Source code and setup notes are available in the project repository.
